# SkillSwap Platform

SkillSwap is a responsive web app where people exchange skills without paying
money. Users can teach a skill they know and learn a skill they want to develop.

## Features
- Home page with hero section and live statistics
- Explore Skills with search and category filters
- Offer Your Skill form with validation and live profile preview
- Skill Swap Requests with Pending, Accepted and Rejected status
- Duplicate request prevention
- How It Works page with a three-step guide and FAQ
- Data saved in localStorage, so it persists after refresh
- Fully responsive for desktop, tablet and mobile

## Tech Stack
React 18, React Router, React Hooks, Vite, HTML, CSS, JavaScript

## Getting Started
1. Clone the repository
2. Run `npm install`
3. Run `npm run dev`
4. Open http://localhost:5173

## Project Structure
- `src/components` reusable UI components
- `src/pages` application pages
- `src/context` global state and localStorage logic
- `src/styles` CSS files

## Note
There is no backend. Replies to swap requests are simulated for demonstration.
